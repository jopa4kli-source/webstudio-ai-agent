# WebStudio AI Agent

محرر WebStudio محلي يعمل داخل المتصفح، مع وكيل برمجي متصل بـ Cloudflare Workers AI.

## الميزات

- محرر ملفات ومعاينة مباشرة.
- محادثة AI باستخدام Worker API.
- إنشاء وتعديل وحذف وإعادة تسمية ملفات المشروع.
- البحث داخل الملفات وملف قدرات الوكيل.
- فحص المشروع والروابط وأخطاء المعاينة.
- كونسول داخلي آمن داخل WebStudio.
- تصدير المشروع كملف ZIP.
- حفظ المشروع محليًا في `localStorage`.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا يحتاج المشروع إلى خادم محلي، لكن يحتاج اتصالًا بالإنترنت لاستدعاء Worker API وتحميل مكتبة ZIP.

## حدود الأمان

الأوامر تعمل داخل مشروع WebStudio والكونسول الداخلي فقط. لا ينفذ الوكيل أوامر نظام التشغيل أو `sudo` أو أوامر shell خارج المشروع.
